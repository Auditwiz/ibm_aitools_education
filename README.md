# IBM AI Tools Learning Hub

A modular interactive curriculum platform for learning about IBM AI tools including WatsonX, Watson Orchestrate, and Consulting Advantage. The app features progress tracking, video lessons, study cards, and quizzes for each module.

## Features

- **Modular Curriculum:** Explore multiple modules, each covering a different IBM AI topic.
- **Interactive Study Cards:** Flip cards to review key concepts.
- **Video Lessons:** Embedded YouTube videos for each module.
- **Quizzes:** Test your understanding, with instant feedback and pass rates.
- **Progress Tracking:** See your progress per module and overall, including visual charts.
- **Responsive Design:** Optimized for desktop and mobile use.
- **Dark Mode & Accessibility:** Visually appealing themes and accessibility features.

## Getting Started

### Prerequisites

- No installation required for basic use: just open `index.html` in a web browser.
- For local development: [Node.js](https://nodejs.org/) and [npm](https://npmjs.com/) (optional, if you plan to package or extend).
- Modern browser (Chrome, Firefox, Edge, Safari).

### Installation

1. **Clone the repository:**
    ```
   (https://auditwiz.github.io/start_your_ai_journey/)
    cd ibm-ai-tools-hub
    ```

2. **Running locally:**
    - Open `index.html` in your browser.
    - All functionality is included and client-side.

3. **Optional: Host on GitHub Pages**
    - Push to a GitHub repository
    - Go to repo Settings > Pages, and select `main` branch and `/root` for deployment
